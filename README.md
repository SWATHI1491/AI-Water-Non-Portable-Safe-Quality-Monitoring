
# 💧 AI-Based Water Quality Monitoring and Potability Prediction System

An interactive **Streamlit dashboard** that explores water-quality measurements and uses a machine-learning model to predict whether a sample is labelled **potable (class 1)** or **non-potable (class 0)** in the benchmark dataset.

> **Important:** This is an educational/research screening project. A model prediction is not a certified drinking-water test and must not be used on its own to decide whether water is safe to drink. Confirm results through an accredited laboratory and follow applicable public-health guidance.

## ✨ Project features

- **Interactive dashboard** built with Streamlit.
- **Single-sample prediction** using nine physicochemical water-quality features.
- **Dataset exploration** with charts for target distribution, feature distributions, missing values, and correlations.
- **Model evaluation** view for metrics such as accuracy, ROC-AUC, precision, recall, F1-score, and confusion matrix when evaluation results are available.
- **Visual summaries** to help users explore the dataset and understand the workflow.
- **Screening checks and recommendations** that are clearly labelled as illustrative—not a validated Water Quality Index (WQI).
- **Downloadable prediction report** (if enabled in the app version you are running).

## 🧪 Dataset

The notebook uses `water_potability.csv`, containing **3,276 rows and 10 columns**: nine input features and the target column `Potability`.

| Column | Description |
|---|---|
| `ph` | pH measurement |
| `Hardness` | Water hardness |
| `Solids` | Dissolved solids measurement in the dataset |
| `Chloramines` | Chloramines measurement |
| `Sulfate` | Sulfate measurement |
| `Conductivity` | Electrical conductivity |
| `Organic_carbon` | Organic carbon measurement |
| `Trihalomethanes` | Trihalomethanes measurement |
| `Turbidity` | Turbidity measurement |
| `Potability` | Target label: `0` = non-potable/unsafe label, `1` = potable/safe label |

The notebook reports missing values in `ph` (491), `Sulfate` (781), and `Trihalomethanes` (162). These missing feature values are handled in the modelling pipeline; the target label should not be imputed.

Target counts in the supplied dataset:

- **Class 0:** 1,998 samples
- **Class 1:** 1,278 samples

The dataset does not contain timestamps, so this project predicts individual samples; it does **not** perform time-series forecasting or provide continuous sensor monitoring unless a separate live data integration is added.

## 🧠 Machine-learning workflow

The supplied notebook uses a scikit-learn pipeline with median imputation and a Random Forest classifier. The notebook's reported model configuration includes class balancing and a fixed random seed.

Typical workflow:

1. Load and inspect the CSV file.
2. Check feature columns, missing values, and target distribution.
3. Separate the nine input features from `Potability`.
4. Split data into training and test sets.
5. Fit preprocessing and the classifier using the training data.
6. Evaluate predictions on held-out data using multiple metrics.
7. Save the trained model and evaluation metrics for the Streamlit app.

Accuracy alone is not enough for this task. Review recall for the unsafe class, the confusion matrix, and ROC-AUC as well. Test-split metrics are preliminary and do not establish real-world or field reliability.

## ⚙️ Installation and setup

### 1. Clone the repository

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub details:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Alternatively, download the repository as a ZIP file and extract it.

### 2. Create and activate a virtual environment (recommended)

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use the environment's Python directly or follow your organisation's permitted execution-policy guidance.

**macOS/Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

If a `requirements.txt` file is present:

```bash
python -m pip install -r requirements.txt
```

Otherwise, install the main packages:

```bash
python -m pip install streamlit pandas numpy scikit-learn joblib plotly matplotlib seaborn jupyter
```

### 4. Prepare the model files

1. Put `water_potability.csv` in the same folder as the notebook.
2. Open `water_analysis_rewritten.ipynb` in Jupyter Notebook or VS Code.
3. Run the notebook cells in order, including the model-training and model-export cells.
4. Confirm that `water_potability_model.joblib` is saved beside `app.py`.
5. If the notebook exports `evaluation_metrics.json`, keep it in the same folder too.

If the notebook does not generate `water_potability_model.joblib`, check that its final export cell has been run and that the output path matches the app's expected filename.

### 5. Run the Streamlit app

From the directory containing `app.py`, run:

```powershell
python -m streamlit run app.py
```

Streamlit prints a local URL in the terminal, for example:

```text
Local URL: http://localhost:8501
```

Open the exact **Local URL** shown in your terminal. The port can vary (for example, `8501` or `8502`) if another Streamlit app is already running.

To stop the app, focus the terminal and press `Ctrl+C`.

## 📊 Evaluation guidance

Use several complementary metrics when evaluating the classifier:

- **Accuracy:** overall fraction of correct predictions.
- **Precision:** among samples predicted as a class, how many were correct.
- **Recall:** among samples truly in a class, how many were identified.
- **F1-score:** harmonic mean of precision and recall.
- **ROC-AUC:** ability to rank positive and negative classes across thresholds.
- **Confusion matrix:** shows the kinds of correct and incorrect classifications.

For a water-safety screening use case, pay special attention to **unsafe-class recall** and false-safe predictions. A model that labels unsafe samples as safe can have serious consequences. Choose thresholds and assess performance based on the intended use, data quality, and independent validation—not on accuracy alone.

## ⚠️ Limitations and responsible use

- The model learns patterns from a benchmark dataset; performance may not generalise to other locations, seasons, water sources, laboratories, or sensors.
- Model probabilities may not be calibrated for real-world samples.
- The available features do not cover every chemical, biological, or physical hazard. In particular, the app does not replace microbiological testing.
- The app's simple parameter screening score is **not a validated WQI** and does not certify compliance with drinking-water standards.
- Units and measurement methods should be verified against the source data before using real measurements.
- Do not use this demo as the sole basis for drinking-water, health, or regulatory decisions.
